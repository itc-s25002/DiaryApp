# DiaryApp

# 日記アプリ（Diary App）

### 1 アプリケーション名

Diary App（日記アプリ）

## 2 機能要件

### 2.1 日記管理機能

| 機能     | 説明                             |
| -------- | -------------------------------- |
| 日記作成 | 新しい日記を作成する             |
| 日記一覧 | 保存されている日記を一覧表示する |
| 日記詳細 | 選択した日記の内容を表示する     |
| 日記編集 | 作成済みの日記を編集する         |
| 日記削除 | 作成済みの日記を削除する         |

### 2.2 日記の入力項目

| 項目     | 説明                     |
| -------- | ------------------------ |
| タイトル | 日記のタイトル           |
| 本文     | 日記の内容               |
| 投稿日   | 日記を作成した日付       |
| 更新日時 | 日記を最後に更新した日時 |

## 3 画面構成

| 画面名       | 説明                 |
| ------------ | -------------------- |
| ホーム画面   | 日記一覧を表示する   |
| 日記作成画面 | 新しい日記を作成する |
| 日記詳細画面 | 日記の内容を表示する |
| 日記編集画面 | 日記の内容を編集する |

## 4 データベース設計（概要）

### diaries テーブル

| カラム名   | データ型     | 説明             |
| ---------- | ------------ | ---------------- |
| id         | INT          | 日記ID（主キー） |
| title      | VARCHAR(255) | タイトル         |
| content    | TEXT         | 本文             |
| created_at | DATETIME     | 作成日時         |
| updated_at | DATETIME     | 更新日時         |
